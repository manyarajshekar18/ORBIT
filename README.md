# 🚀 ORBIT - Project Management Application

ORBIT is a project management application built to manage projects, tasks, and project progress from one place.

The project is being developed step by step as part of my MERN Stack learning journey.

---

## 📌 Project Overview

ORBIT allows users to:

- View different projects
- Select a project
- Manage tasks for each project
- Add new tasks
- Mark tasks as completed or pending
- Delete tasks
- Change project status
- Save tasks and project statuses in browser storage
- Keep data after refreshing the page
- Use the application on desktop and mobile screens
